# Changelog

All notable changes to 3012 are documented in this file. The project follows semantic versioning after the first stable release.

## [Unreleased]

### Added

- Clean SwiftUI app shell for Store, Installed, Downloads, and Settings.
- Shared iOS system-oriented design primitives.
- Xcode project and shared `3012` scheme.
- GitHub Actions workflow that builds an unsigned IPA.
- Public architecture, development, usage, security, contribution, and attribution documentation.

### Not implemented yet

- Remote catalog client and signature verification.
- Background download manager.
- `.3012pkg` package codec.
- Apply, backup, transaction, and restore engine.

## [0.1.0-dev] - 2026-08-18

- Established the independent 3012 repository baseline.
